# Practice App — Functional Documentation

[← Practice app](../README.md)

Describes what users can do with the practice app, one folder per feature.

The use cases aren't defined yet, so there are no feature pages. When a feature's use
cases are agreed, add a folder for it with one file per use case and link it here.
The expected features are:

- `library/`: importing dictionary entries and kanji, and customising them.
- `collections/`: grouping items, and using collections as tags.
- `exercises/`: practising with one or more collections.

Until then, the [technical documentation](../technical/README.md) describes the model
that is already built.
